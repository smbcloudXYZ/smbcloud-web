The [smbCloud Console](https://console.smbcloud.xyz) is now in public beta.

## What is the smbCloud Console?

The smbCloud Console is our web interface for deploying apps and managing projects. It gives small and medium-sized teams a simpler way to handle cloud tasks that usually turn into manual setup.

### Key features

- **GitHub integration**: Connect your GitHub account and deploy projects from your repos
- **One-click deployments**: Launch Node.js, Swift (Vapor), and Ruby (Rails) apps
- **Real-time monitoring**: Check deployments, logs, and resource usage as they happen
- **Team collaboration**: Invite teammates and manage permissions
- **Secure by default**: Built with sane defaults for auth and data protection

## Get started

[Sign in to the console](https://console.smbcloud.xyz), connect your GitHub account, and deploy your app. The beta is still early, so feedback helps us see where the rough edges are.

The goal is simple: make deployment and day-to-day project management easier without burying teams in cloud jargon.
