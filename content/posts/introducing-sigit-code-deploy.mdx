## Meet siGit Code & Deploy

siGit Code & Deploy is our mobile Git client, code editor, and deployment tool for developers who need more than a basic repo viewer. You can review pull requests, make quick edits, push changes, and trigger deployments from your phone or tablet.

### Why siGit Code & Deploy?

- **Built for real Git work**: Handle everyday Git tasks, code edits, and deployments from one app.
- **Mobile-first**: Designed for touch without stripping out the features developers actually use.
- **Rust-powered**: Fast, stable, and memory-safe, even with larger repositories.
- **Deployment control**: Trigger deployments, manage pipelines, and check status without switching devices.
- **Code editor**: Syntax highlighting, code completion, and editing tools tuned for mobile.

### Key features

- **Advanced Git operations**: Rebase, cherry-pick, stash, and manage branches
- **Deployment pipelines**: Configure and trigger deployments
- **Repository management**: Clone, fork, and manage repositories across providers
- **Touch-optimized interface**: Controls designed for mobile workflows
- **Secure by default**: Credentials and code stay protected
